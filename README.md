# Sitio web para Contadora Económica

Estructura base del sitio con HTML, CSS y un pequeño script de alternancia de tema para un estilo profesional y responsive.

Estructura de archivos:
- `index.html` — estructura semántica y contenido de la página.
- `assets/css/styles.css` — estilos principales, incluyendo modo claro y modo oscuro.
- `assets/js/theme-toggle.js` — alterna entre modo claro y modo oscuro.
- `assets/svg/` — gráficos SVG para la ilustración y placeholder de foto.
- `assets/fotos/anetjpg.jpg` — foto real para la sección "Sobre mí".

Notas importantes:
- El formulario de contacto usa `mailto:antimiela41@gmail.com` para abrir el cliente de correo del usuario.
- El modo oscuro se activa manualmente con el botón "Modo oscuro" en la cabecera.
- El modo claro usa los colores originales de la página y es el estado predeterminado.

Instrucciones rápidas:
1. Abrir `index.html` en el navegador.
2. Reemplazar los textos y servicios de ejemplo con tu información.
3. Cambiar la imagen en `assets/fotos/anetjpg.jpg` si quieres usar otra foto.
4. Si quieres editar el modo oscuro o los colores, modifica `assets/css/styles.css`.
